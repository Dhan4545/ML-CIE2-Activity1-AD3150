# Machine Learning CIE 2 - Activity 1

## Activity Name
Dataset Preparation

## Dataset Information
- Dataset: Titanic Dataset
- Source: Seaborn Dataset
- File Format: CSV
- Task: Data cleaning and preprocessing

## Work Performed
1. Loaded and inspected the dataset.
2. Checked rows, columns and data types.
3. Identified missing values.
4. Handled missing values using median and mode.
5. Checked duplicate records.
6. Performed Exploratory Data Analysis (EDA).
7. Created visualizations.
8. Encoded categorical variables.
9. Scaled numerical features.
10. Saved the prepared dataset as a CSV file.
